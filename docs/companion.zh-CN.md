# WhatIfStarRail · 星铁如果说

> 如果你能在那一刻开口，故事会不会不一样？

面向 **Honkai: Star Rail / 崩坏：星穹铁道** 的剧情捕捉、角色对话与分支改写工作台。

这是一个运行在游戏旁边的非官方伴游插件原型。它通过屏幕区域 OCR 读取可见字幕，将剧情保存在独立的故事图中；不注入游戏进程，不改写客户端任务、资源或存档。人物心境和后续故事属于同人推演。

## 启动

```powershell
python -m pip install -e ".[dev,capture,llm]"
python -m astral_agents.cli ui
```

打开 `http://localhost:8501/?mode=companion`，或者在侧栏切换到「星铁伴游」。原有多人物模拟台仍然可用。

## 边玩边捕捉

1. 将游戏设为窗口化或无边框窗口。在「字幕区域与后台采集」选择预设或填写屏幕坐标和在场人物，并保存配置。区域应包含说话人和台词。
2. 点击「预览已保存的字幕区域」，确认没有截到伴游页面；多屏时使用整个桌面的坐标，可以为负数。
3. 点击「启动后台捕捉」。本地 RapidOCR 按设定间隔（界面支持 0.5–10 秒）读取一次指定区域，按设置的置信度阈值（默认 0.75）过滤文本，连续两次结果一致后保存。
4. 捕捉记录按顺序连接；新记录保存在后台；点击「打开最新捕捉剧情」可切换，避免自动切换打断编辑。暂停捕捉后可切换历史节点进行对话和改写。
5. 切换任务或开新一段游戏时，停止采集后勾选「本次开始新的捕捉时间线」并重新启动，避免不同场景拼接在一起。

只会捕捉玩家实际显示的文字，不能读取未显示剧情、隐藏任务状态或角色真实内心。台词停留时间短于两个采样周期、动态背景、低分辨率、遮挡、黑屏和 OCR 错字都可能造成漏记。关闭页面仍会持续采集，直到手动停止或 Python 服务退出；此版本不包含常驻游戏内悬浮窗。截图仅在进程内处理，不持久保存，也不发送模型。可通过手动节点补录，或创建校正分支保留原始记录。

## 跨屏对话和魔改

- 「伴游控制台」的手动开局可输入任何剧情节点或完全原创开局，并填写任意人物，不局限于原模拟器中的四人。
- 「故事档案」选中节点，修改剧情前提及在场人物，创建分支。原节点保持不变。
- 「自然演进一轮」将人物行动、对话及后果保存为子节点，可反复续演或从历史节点另开分支。
- 「跨屏对话」按当前节点和人物保存独立历史。切换分支不会带入兄弟分支的对话。
- 导出 JSON 包含所选节点的祖先链及其对话，供留存与比较；可在「故事档案」验证并导入本项目 v1 JSON，使用新节点 ID 保留原记录。

默认离线模式是明确标注的固定流程示意。要生成情境化对话与完整故事，启动服务前设置：

```powershell
$env:OPENAI_API_KEY = "你的密钥"
$env:ASTRAL_OPENAI_MODEL = "你有权限使用的模型名称"
python -m astral_agents.cli ui
```

再开启侧栏「使用模型生成」。仅发送当前分支最近 16 个节点和这些节点中当前人物最近 8 轮对话；长篇故事应手动建立摘要节点以保留更早的关键事实。模型无法保证绝对无剧透或完全符合官方设定，提示词要求局限于当前情境并区分推测。调用失败会显示错误，不创建虚假后续。

## 数据与架构

- `src/astral_agents/companion.py`：SQLite 故事图、隔离对话、分支导出、模型生成、OCR 稳帧缓冲。
- `app/companion_ui.py`：控制台、故事、对话、角色与设置五个工作区；定时片段只观察采集状态。
- `src/astral_agents/capture_service.py`：后台线程执行采集，独立于浏览器会话。
- `src/astral_agents/bridge_api.py`：可选的本地认证接入 API，详见 [接口文档](bridge-api.zh-CN.md)。
- `runs/companion.sqlite`：本地持久存储，已被 Git 忽略。可用 `ASTRAL_COMPANION_DATABASE` 指定路径。
- 每次改写与续演新增节点，外键保证父节点存在；不会修改原模拟引擎的事件日志。

这是单机个人工作台，访问者可读取本地故事；建议仅绑定 localhost，不直接作为公网多用户服务部署。

采集适配参考：[MSS 区域采集文档](https://python-mss.readthedocs.io/latest/usage.html)、[RapidOCR](https://github.com/RapidAI/RapidOCR)。


## v0.2 新增工作流

在「角色档案」编辑身份、语气与知识边界；生成时只带入当前人物或当前在场人物的角色卡。在「连接与设置」可保存模型名称，选择 Responses / Chat Completions 协议，并查看依赖是否安装。兼容服务地址使用 OPENAI_BASE_URL 环境变量配置。

故事档案支持搜索标题、人物和正文、来源筛选、祖先时间轴、父子文本对照和归档校验导入。导入不覆盖现有故事，也不导入密钥、配置或角色卡。
