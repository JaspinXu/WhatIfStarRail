# 星铁伴游工作台

这是一个运行在游戏旁边的非官方伴游插件原型。它通过屏幕区域 OCR 读取可见字幕，将剧情保存在独立的故事图中；不注入游戏进程，不改写客户端任务、资源或存档。人物心境和后续故事属于同人推演。

## 启动

```powershell
python -m pip install -e ".[dev,capture,llm]"
python -m astral_agents.cli ui
```

打开 `http://localhost:8501/?mode=companion`，或者在侧栏切换到「星铁伴游」。原有多人物模拟台仍然可用。

## 边玩边捕捉

1. 将游戏设为窗口化或无边框窗口。在「实时字幕捕捉」填写字幕区域的屏幕坐标和在场人物。区域应包含说话人和台词。
2. 点击「预览字幕区域」，确认没有截到伴游页面；多屏时使用整个桌面的坐标，可以为负数。
3. 开启「开始自动捕捉」。本地 RapidOCR 每 2–10 秒读取一次指定区域，仅保留置信度至少 0.75 的文本，连续两次结果一致后保存。
4. 捕捉记录按顺序连接；新记录自动成为当前节点。暂停捕捉后可切换历史节点进行对话和改写。
5. 切换任务或开新一段游戏时，点击「开始新的捕捉时间线」，避免不同场景拼接在一起。

只会捕捉玩家实际显示的文字，不能读取未显示剧情、隐藏任务状态或角色真实内心。台词停留时间短于两个采样周期、动态背景、低分辨率、遮挡、黑屏和 OCR 错字都可能造成漏记。页面需保持连接，浏览器后台节流可能降低采样速度；此版本不包含常驻游戏内悬浮窗。截图仅在进程内处理，不持久保存，也不发送模型。可通过手动节点补录，或创建校正分支保留原始记录。

## 跨屏对话和魔改

- 「剧情接入」可输入任何剧情节点或完全原创开局，并填写任意人物，不局限于原模拟器中的四人。
- 「分支工作室」选中节点，修改剧情前提及在场人物，创建分支。原节点保持不变。
- 「自然演进一轮」将人物行动、对话及后果保存为子节点，可反复续演或从历史节点另开分支。
- 「跨屏对话」按当前节点和人物保存独立历史。切换分支不会带入兄弟分支的对话。
- 导出 JSON 包含所选节点的祖先链及其对话，供留存与比较；本版本尚无 JSON 导入界面。

默认离线模式是明确标注的固定流程示意。要生成情境化对话与完整故事，启动服务前设置：

```powershell
$env:OPENAI_API_KEY = "你的密钥"
$env:ASTRAL_OPENAI_MODEL = "你有权限使用的模型名称"
python -m astral_agents.cli ui
```

再开启侧栏「使用模型生成」。仅发送当前分支最近 16 个节点和当前人物最近 8 轮对话；长篇故事应手动建立摘要节点以保留更早的关键事实。模型无法保证绝对无剧透或完全符合官方设定，提示词要求局限于当前情境并区分推测。调用失败会显示错误，不创建虚假后续。

## 数据与架构

- `src/astral_agents/companion.py`：SQLite 故事图、隔离对话、分支导出、模型生成、OCR 稳帧缓冲。
- `app/companion_ui.py`：接入、分支和对话三种视图，Streamlit 定时片段执行本机采集。
- `runs/companion.sqlite`：本地持久存储，已被 Git 忽略。可用 `ASTRAL_COMPANION_DATABASE` 指定路径。
- 每次改写与续演新增节点，外键保证父节点存在；不会修改原模拟引擎的事件日志。

这是单机个人工作台，访问者可读取本地故事；建议仅绑定 localhost，不直接作为公网多用户服务部署。

采集适配参考：[MSS 区域采集文档](https://python-mss.readthedocs.io/latest/usage.html)、[RapidOCR](https://github.com/RapidAI/RapidOCR)。
