# 两分钟原型演示指南

## 准备

```powershell
python -m pip install -e ".[dev]"
astral ui
```

浏览器打开后，左侧选择“离线启发式（推荐）”。这个模式不需要 API Key。

## 演示脚本

### 0–15 秒：解释三层信息

点击“快速演示”。指出顶部状态：

- 任务完成；
- 第 10 / 12 轮；
- 状态有效；
- 越界知情 0；
- 固定随机种子。

说明公开设定不可修改，世界真相只由事件更新，角色认知可能不完整。

### 15–40 秒：展示行动如何成为事件

在“运行台”查看本轮四张行动卡：

1. 每个角色从同一轮首快照获得独立观察；
2. 角色只提出行动意图；
3. 裁决器生成已确认事件；
4. reducer 生成资源、位置、线索和阶段的 before / after。

向下滚动事件时间线，指出每个事件都有稳定 ID 与可见范围。

### 40–75 秒：对比角色视角

进入“角色视角”，先选择三月七，再切换丹恒。

- 展开 `ObservationPacket`，展示其中没有完整 `WorldState`；
- 查看独立记忆的来源事件 ID；
- 查看“为什么做出这个行动”中的证据事件；
- 开启“研究者审计模式”，展示信息边界矩阵；
- 强调矩阵只属于审计视图，不会进入角色决策输入。

### 75–100 秒：确定性回放

进入“回放”，把滑杆移到第 2 轮：

- 查看这一轮事件；
- 查看与上一轮的状态差异；
- 展开种子、配置摘要、状态摘要和时间线哈希；
- 指出页面底部“全量重放通过”。

### 100–120 秒：章节与导出

进入“章节与导出”：

- 展示 4 个章节；
- 展开一个章节的来源事件；
- 指出新增推断为 0、连续性校验通过；
- 下载默认脱敏 ZIP。

默认包不会包含私密 payload、角色记忆或决策理由。完整研究 trace 必须显式开启。

## 单步版本

若需要现场展示模拟过程：

1. 左侧点击“单步新建”；
2. 点击“推进一轮”观察首轮四个隔离调查；
3. 连续点击“推进三轮”；
4. 随时切换到“回放”，已经提交的轮次都是保存点；
5. 点击“运行至结局”完成余下轮次。

## 验收口径

演示成功应同时满足：

- 无 API Key 完成任务；
- 10 轮、4 个章节；
- 越界知情与严重连续性错误均为 0；
- 角色视角没有其他角色私密事实；
- 回放摘要一致；
- 默认导出经过脱敏；
- 页面始终显示非官方研究声明。
